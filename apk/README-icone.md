# Icône de l'application

Pour donner votre propre image à l'application :

1. Enregistrez votre image sous **`apk/icone.png`** (format PNG, carrée de préférence,
   par exemple 512×512 ou 1024×1024, fond noir conseillé).
2. Committez-la et poussez sur `main` : le build l'utilise automatiquement comme icône
   (icône classique, ronde, et icône adaptative Android 8+, sur fond noir).

Si `apk/icone.png` est absent, l'icône par défaut de Termux est conservée.
